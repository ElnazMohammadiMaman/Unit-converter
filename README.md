# Unit Converter 🧮

A simple and beginner-friendly unit converter written in Python.

This project can convert different measurement units including **length**, **weight**, and **temperature**.
It was created to practice Python fundamentals such as dictionaries, conditional statements, user input handling, and error handling.

## Features ✨

### Length Converter

Supported units:

* Millimeter (mm)
* Centimeter (cm)
* Meter (m)
* Kilometer (km)

### Weight Converter

Supported units:

* Milligram (mg)
* Gram (g)
* Kilogram (kg)
* Ton
* Pound (lb)
* Ounce (oz)

### Temperature Converter

Supported units:

* Celsius (C)
* Fahrenheit (F)
* Kelvin (K)

## Error Handling

The program can handle:

* Invalid unit inputs
* Invalid number inputs

## Technologies Used

* Python 3

## How to Run

1. Clone this repository:

```bash
git clone your-repository-link
```

2. Run the program:

```bash
python unit_converter.py
```
